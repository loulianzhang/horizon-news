## [LG Monitors Install Software via Windows Update Without Consent](https://videocardz.com/newz/lg-monitors-silently-install-software-through-windows-update-without-user-consent) ⭐️ 8.0/10

LG monitors are silently installing software through Windows Update without user consent, raising serious security and privacy concerns. This issue highlights a significant breach of user trust and could potentially expose users to malware, impacting the security and privacy of their systems. The software is installed as soon as an LG monitor is connected via HDMI, and it has full system access with no sandboxing. It starts with every system boot and can be installed even if the user already had an older LG monitor.

hackernews · baranul · Jul 18, 10:21 · [Discussion](https://news.ycombinator.com/item?id=48956688)

**Background**: Windows Update is a service provided by Microsoft that automatically downloads and installs updates for the Windows operating system. Typically, these updates include security patches, driver updates, and other critical updates. However, in this case, LG's software is being installed without user consent, which is unusual and concerning.
