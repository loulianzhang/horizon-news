## [AirLLM Enables 70B LLM Inference on 4GB GPU](https://github.com/lyogavin/airllm) ⭐️ 7.0/10

AirLLM, a new open-source Python library, now allows the inference of a 70 billion parameter language model on a single 4GB GPU, using a layer-by-layer approach. This breakthrough makes it possible to run large language models on consumer-grade hardware, democratizing access to powerful AI and enabling more widespread use and experimentation. AirLLM achieves this by loading and processing one transformer layer at a time from disk, rather than keeping the entire model in GPU memory. This method significantly reduces the memory requirements for inference.
