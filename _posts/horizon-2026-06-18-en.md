## [Z.ai Releases GLM-5.2, a 753B Parameter LLM](https://simonwillison.net/2026/Jun/17/glm-52/#atom-everything) ⭐️ 9.0/10

Z.ai has released GLM-5.2, a 753 billion parameter, 1.51TB text-only LLM with a 1 million token context window, under an MIT license. This release is significant because it sets a new benchmark for open-source LLMs, outperforming other leading models in various benchmarks and generating substantial interest in the AI community. GLM-5.2 uses 40 active parameters (Mixture of Experts) and is noted for its high token usage, consuming 43k output tokens per task, which is more than other leading open weights models.

rss · Simon Willison · Jun 17, 23:58

**Background**: A Mixture of Experts (MoE) is a machine learning technique where multiple expert networks are used to divide a problem space into homogeneous regions. A 1 million token context window allows the model to process and generate much longer sequences of text, making it suitable for tasks like whole-repository code review.
