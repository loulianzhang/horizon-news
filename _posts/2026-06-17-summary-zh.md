## [RFC 10008 引入新的 HTTP QUERY 方法](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 7.0/10

RFC 10008 提出了一种新的 HTTP 方法 QUERY，以解决特定用例并提高网络请求的幂等性。 这种新方法旨在为处理带有请求体的安全和幂等查询提供一种更合适且标准化的方式，从而可以提高 Web API 的可靠性和效率。 QUERY 方法被设计为既安全又幂等，可以在 GET 或 POST 不理想的情况下使用。它还解决了历史互操作性问题，并严格遵守 HTTP 架构定义。

hackernews · schappim · Jun 17, 10:51 · [社区讨论](https://news.ycombinator.com/item?id=48568502)

**背景**: HTTP 方法是网络通信的基础，定义了对指定资源执行的操作。常见的方法包括 GET（用于检索数据）和 POST（用于提交数据）。引入 QUERY 的目的是填补这些方法不足的地方，特别是在处理带有请求体的复杂、幂等查询时。

一个新的名为<click-to-play>的 Web 组件允许用户按需加载 GIF，通过仅在点击时加载 GIF 来提高页面性能。 这个工具对网页开发者来说非常重要，因为它可以提升用户体验并优化页面加载时间，特别是在包含大 GIF 的页面上。 <click-to-play>组件将静态图像转换为可点击的按钮，按需加载 GIF。它使用渐进增强技术构建，可以轻松集成到网页项目中。
