## [RFC 10008 Introduces New HTTP QUERY Method](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 7.0/10

RFC 10008 proposes a new HTTP method, QUERY, to address specific use cases and improve idempotence in web requests. This new method aims to provide a more suitable and standardized way for handling safe and idempotent queries with request bodies, which can enhance the reliability and efficiency of web APIs. The QUERY method is designed to be both safe and idempotent, allowing it to be used in scenarios where GET or POST might not be ideal. It also addresses historical interoperability issues and strict compliance with HTTP architectural definitions.

hackernews · schappim · Jun 17, 10:51 · [Discussion](https://news.ycombinator.com/item?id=48568502)

**Background**: HTTP methods are fundamental to web communication, defining the actions to be performed on the specified resources. Common methods include GET (for retrieving data) and POST (for submitting data). The introduction of QUERY aims to fill a gap where these methods fall short, particularly in handling complex, idempotent queries with request bodies.
