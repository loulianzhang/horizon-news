## [LLM 0.32 增加推理痕迹、OpenAI 集成和服务器端工具](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32 引入了可见的推理痕迹、服务器端工具以及与 OpenAI Responses API 的集成，还新增了一个默认模型 GPT-5.6 Luna。 这些功能增强了 LLM 的透明度和功能性，使其对需要理解和控制 AI 决策过程的开发人员和研究人员更加有用。 推理痕迹显示在标准错误输出中，并可以通过 -R/--hide-reasoning 标志关闭。新版本还包括对代码执行和网络搜索等服务器端工具的支持，以及一个新的端点命令，用于在任何兼容 OpenAI 的端点上执行提示。

**背景**: LLM 是一个用于处理大型语言模型的命令行界面（CLI）工具。推理痕迹提供了对模型思维过程的洞察，而服务器端工具通过允许模型执行代码执行和网络搜索等任务来扩展其功能。

## [llm-anthropic 0.26 发布新增模型和工具](https://simonwillison.net/2026/Aug/4/llm-anthropic/#atom-everything) ⭐️ 7.0/10

llm-anthropic 0.26 版本引入了新的模型，如 claude-fable-5、claude-sonnet-5 和 claude-opus-5，以及用于 WebSearch、WebFetch、CodeExecution 和 AnthropicMCP 的服务器端工具。 这些新增功能增强了 llm-anthropic 库的功能和集成选项，为开发人员提供了更强大和多用途的工具来处理大型语言模型。 新的模型和工具可以通过 LLM 的 -T 接口或 Python 的 tools= 使用。之前的 -o web_search* 选项已被移除，改为使用 -T WebSearch。推理、工具调用和结果现在以类型化事件的形式流式传输，除非传递了 --hide-reasoning/-R，否则 CLI 提示的推理将显示在标准错误中。

rss · Simon Willison · Aug 4, 22:00

**背景**: llm-anthropic 是一个提供访问 Anthropic 大型语言模型的库。新模型之一的 Claude Fable 5 是一个在编码、知识工作、视觉和计算机使用方面具有先进能力的模型。AnthropicMCP（模型上下文协议）是一个连接 AI 模型与工具、数据和 API 的开放标准。
