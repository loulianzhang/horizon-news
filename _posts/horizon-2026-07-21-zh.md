## [Nativ：在 Mac 上本地运行 AI 模型](https://simonwillison.net/2026/Jul/21/nativ/#atom-everything) ⭐️ 7.0/10

MLX-VLM Python 库的开发者 Prince Canuma 发布了一款新的 macOS 桌面应用程序 Nativ，允许用户在本地运行 AI 模型，并提供聊天界面和本地主机 API 服务器。 这款工具通过允许开发人员在本地运行模型而无需使用云服务，使 AI 更加易于访问，从而降低了成本并提高了隐私性。它还与现有的 Hugging Face 模型缓存集成良好，增强了可用性。 Nativ 将 MLX-VLM 库封装成一个完整的 macOS 桌面应用程序，类似于 LM Studio。它支持聊天界面和本地主机 API 服务器，并且可以自动检测并使用 Hugging Face 缓存目录中的模型。

**背景**: MLX-VLM 是一个 Python 库，用于在 Mac 上使用 MLX 运行视觉语言模型（VLMs）和全模态模型（具有音频和视频支持的 VLMs）。视觉语言模型是多模态 AI 模型，可以根据视觉输入处理和生成文本。
