## [Nub: A New All-in-One Toolkit for Node.js](https://github.com/nubjs/nub) ⭐️ 7.0/10

Nub, a new toolkit for Node.js, enhances the runtime with transpilation, module resolution, and polyfills, while leveraging the existing Node.js engine and standard library. Nub provides a more seamless and efficient development experience by integrating essential features directly into the Node.js runtime, potentially reducing the need for additional tools and improving performance. Nub uses a preload hook to add a transpiler (powered by oxc and packaged as a Node-API add-on), registers a module resolution hook, and injects polyfills as needed. It is purely additive and runs on the stock Node.js engine and standard library.

hackernews · colinmcd · Jun 24, 14:14 · [Discussion](https://news.ycombinator.com/item?id=48660267)

**Background**: A transpiler is a source-to-source translator that converts code from one programming language to another, often at a similar level of abstraction. Module resolution is the process by which a system locates and loads modules in a program. Polyfills are pieces of code that provide modern functionality on older environments that do not natively support it.
