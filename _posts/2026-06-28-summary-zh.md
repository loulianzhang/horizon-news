## [关于排除敏感文件的 OpenAI Codex GitHub 问题](https://github.com/openai/codex/issues/2847) ⭐️ 7.0/10

一个 GitHub 问题和 Hacker News 讨论强调了需要一种方法来排除 OpenAI Codex 访问敏感文件，社区成员提出了各种解决方案并讨论了最佳方法。 这个问题很重要，因为它解决了一个关键的安全和隐私问题，确保在使用 AI 编码助手时不会无意中暴露或上传敏感数据。 社区成员建议的解决方案包括更改文件权限、在没有敏感文件的容器中运行 Codex 以及使用选择加入机制。还有一些人提议构建自定义沙箱终端并使用现有的系统工具如`chmod`。

hackernews · pikseladam · Jun 28, 12:27 · [社区讨论](https://news.ycombinator.com/item?id=48706714)

**背景**: OpenAI Codex 是由 OpenAI 开发的一个大型语言模型，用于将自然语言提示翻译成源代码。它于 2021 年发布，是 GPT-3 的修改版本，并针对多种编程语言的源代码进行了微调。该模型用于自动化软件工程任务，但如果管理不当，可能会访问和上传敏感文件。

## [密歇根州提案禁止下班后工作沟通](https://www.cbsnews.com/detroit/news/workplace-boundaries-act-employees-after-hours/) ⭐️ 7.0/10

hackernews · cebert · Jun 28, 14:46 · [社区讨论](https://news.ycombinator.com/item?id=48707769)

**背景**: 工作与生活的平衡已成为许多行业中的关键问题，员工经常感到需要在正常工作时间之外保持可用。像这样的立法旨在明确划分工作和个人时间的界限。

**社区讨论**: 社区评论突显了意见的多样性，一些人支持基于补偿的解决方案，而另一些人则强调立法保护的必要性。还有人呼吁对那些经历不同工作条件的人给予更多的理解和同情。
