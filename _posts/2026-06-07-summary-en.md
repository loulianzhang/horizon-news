## [Lathe: LLM-Powered Tool for Hands-On Learning](https://github.com/devenjarvis/lathe) ⭐️ 8.0/10

Lathe, a new tool, uses LLMs to generate hands-on, source-backed tutorials for technical topics, allowing users to learn by doing. This tool addresses the gap in high-quality, human-written tutorials for niche or emerging technical domains, making it easier for learners to acquire new skills. Lathe is a Go CLI that integrates with LLM agent skills like Claude Code, Cursor, and Codex. It provides features such as a table of contents, side-notes, exercises, and sources for deeper learning.

## [29th IOCCC 2025 Winners Announced](https://www.ioccc.org/2025/) ⭐️ 7.0/10

The 29th International Obfuscated C Code Contest (IOCCC) 2025 has announced its winners, featuring innovative and creatively obfuscated C code entries. This contest highlights the creativity and technical prowess of programmers, showcasing the art of writing highly obfuscated yet functional C code, which can inspire and challenge the programming community. Notable entries include a GameBoy emulator whose code visually resembles a GameBoy, and a 366字节的C程序虚拟机能够运行Linux和Doom，实现了一种单指令集计算机（OISC）。这些条目展示了代码混淆技术的极限。

hackernews · matt_d · Jun 7, 05:47 · [Discussion](https://news.ycombinator.com/item?id=48432199)

**Background**: The International Obfuscated C Code Contest (IOCCC) is an annual programming competition that challenges participants to create the most creatively obfuscated C programs. The contest aims to highlight the importance of clear and readable code by showcasing extreme examples of the opposite. Winning entries are awarded with various categories and announced on the official IOCCC website.
