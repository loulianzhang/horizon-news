## [Nativ: Run AI Models Locally on Your Mac](https://simonwillison.net/2026/Jul/21/nativ/#atom-everything) ⭐️ 7.0/10

Prince Canuma, the developer of the MLX-VLM Python library, has released Nativ, a new macOS desktop application that allows users to run AI models locally, providing both a chat interface and a localhost API server. This tool makes AI more accessible to developers by allowing them to run models locally without the need for cloud services, which can be costly and less private. It also integrates well with existing Hugging Face model caches, enhancing usability. Nativ wraps the MLX-VLM library in a full macOS desktop application, similar to LM Studio. It supports both a chat interface and a localhost API server, and it can automatically detect and use models from the Hugging Face cache directory.

**Background**: MLX-VLM is a Python library for running vision language models (VLMs) and omni models (VLMs with audio and video support) on a Mac using MLX. Vision language models are multimodal AI models that can process and generate text based on visual inputs.
