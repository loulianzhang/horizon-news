## [OpenWrt One: An Open Hardware Router](https://openwrt.org/toh/openwrt/one) ⭐️ 7.0/10

The OpenWrt One, an open hardware router, has been introduced, supporting the OpenWrt firmware and offering flexibility and extended life for networking devices. This router allows users to extend the life of their networking devices and gain additional capabilities, making it a valuable tool for those who need more control over their network configurations. The OpenWrt One supports the OpenWrt firmware, which is known for its customizability and extensibility. However, some users have noted that it lacks hardware PPPoE offloading, which can be a limitation for high-speed fiber connections.

sqlite-utils 4.0rc3 has been released, introducing support for compound foreign keys and case-insensitive column names. These new features enhance database management and schema design, making it easier to handle complex relationships and improve data integrity. The support for compound foreign keys involves a subtle breaking change to the table.foreign_keys method, and the case-insensitive column names affect multiple parts of the library.

**Background**: sqlite-utils is a utility library for working with SQLite databases, providing tools to create, populate, and manage databases. Compound foreign keys are composite keys where each attribute is a foreign key in its own right, enhancing data integrity and relationship management.
