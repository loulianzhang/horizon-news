## [Lathe：基于大语言模型的动手学习工具](https://github.com/devenjarvis/lathe) ⭐️ 8.0/10

新的工具 Lathe 使用大语言模型生成动手实践、有源代码支持的技术主题教程，让用户通过实践来学习。 该工具解决了高质量、人工编写教程在小众或新兴技术领域的缺失问题，使学习者更容易掌握新技能。 Lathe 是一个 Go 命令行工具，集成了像 Claude Code、Cursor 和 Codex 这样的大语言模型代理技能。它提供了目录、旁注、练习和深入学习的资源等功能。

**背景**: 大语言模型（LLM）代理技能是可定制的工作流程，可以根据特定需求教会大语言模型执行特定任务。Go 命令行接口（CLI）工具以其速度快、可移植性和易于创建和安装而闻名。

## [第 29 届 IOCCC 2025 获奖者公布](https://www.ioccc.org/2025/) ⭐️ 7.0/10

第 29 届国际 C 代码混淆大赛（IOCCC）2025 年公布了获奖者，展示了创新且极具创意的 C 代码作品。 这项比赛突显了程序员的创造力和技术水平，展示了编写高度混淆但功能完整的 C 代码的艺术，可以激励和挑战编程社区。 值得注意的条目包括一个代码看起来像 GameBoy 的游戏机模拟器，以及一个 366 字节的 C 程序虚拟机，能够运行 Linux 和 Doom，实现了一种单指令集计算机（OISC）。这些条目展示了代码混淆技术的极限。

hackernews · matt_d · Jun 7, 05:47 · [社区讨论](https://news.ycombinator.com/item?id=48432199)

**背景**: 国际 C 代码混淆大赛（IOCCC）是一项年度编程竞赛，挑战参赛者编写最具创意的混淆 C 代码。该比赛通过展示极端的反例来强调清晰可读代码的重要性。获奖作品会被授予各种类别，并在 IOCCC 官方网站上公布。
