## [LLM 0.32 Adds Reasoning Traces, OpenAI Integration, and Server-Side Tools](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32 introduces support for visible reasoning traces, server-side tools, and integration with the OpenAI Responses API, along with a new default model, GPT-5.6 Luna. These features enhance the transparency and functionality of LLM, making it more useful for developers and researchers who need to understand and control the AI's decision-making process. Reasoning traces are displayed in standard error, and can be turned off with the -R/--hide-reasoning flag. The new version also includes support for server-side tools like code execution and web search, and a new endpoint command for executing prompts against any OpenAI-compatible endpoint.

rss · Simon Willison · Aug 4, 23:58

**Background**: LLM is a command-line interface (CLI) tool for working with large language models. Reasoning traces provide insight into the model's thought process, while server-side tools extend the capabilities of the model by allowing it to perform tasks such as code execution and web searches.

## [llm-anthropic 0.26 Release Adds New Models and Tools](https://simonwillison.net/2026/Aug/4/llm-anthropic/#atom-everything) ⭐️ 7.0/10

The llm-anthropic 0.26 release introduces new models such as claude-fable-5, claude-sonnet-5, and claude-opus-5, along with server-side tools for WebSearch, WebFetch, CodeExecution, and AnthropicMCP. These additions enhance the functionality and integration options of the llm-anthropic library, providing developers with more powerful and versatile tools for working with large language models. The new models and tools are available through LLM's -T interface or Python tools=. The previous -o web_search* options have been removed in favor of -T WebSearch. Reasoning, tool calls, and results now stream as typed events, and reasoning for CLI prompts is displayed to standard error unless --hide-reasoning/-R is passed.

rss · Simon Willison · Aug 4, 22:00

**Background**: llm-anthropic is a library that provides access to Anthropic's large language models. Claude Fable 5, one of the new models, is a state-of-the-art model known for its capabilities in coding, knowledge work, vision, and computer use. AnthropicMCP (Model Context Protocol) is an open standard for connecting AI models to tools, data, and APIs.
